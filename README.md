# คำสั่ง github

# คำสั่งเริ่มต้นโปรเจค
1. git init --> สร้างคลัง Git ใหม่ในโฟลเดอร์ปัจจุบัน
2. git clone url --> คัดลอก ดาวโหลด โปรเจกกิตฮับลงมาที่เครื่อง

# คำสั่งจัดการไฟล์และบันทึกข้อมูล workflow
1. git status --> เช็คสถานะปัจจุบันของไฟล์ในโปรเจคต์ สามารถดูว่าไฟล์ไหนแก้ไขแล้วหรือยังไม่ได้เพิ่ม
2. git add . --> เพิ่มไฟล์ทั้งหมดในโฟลเดอร์เข้าสู่เสตจเตรียมบันทึก
3. git add <ชื่อไฟล์> --> เลือกเพิ่มเฉพาะไฟล์ที่ระบุ
4. git commit -m "text" --> บันทึกประวัติการเปลี่ยนแปลงลงเครื่องคอมพิวเตอร์พร้อมใส่คำอธิบาย

# คำสั่งเชื่อมต่อกับ GitHub Remote Repositories
1. git remote add origin https://... --> ผูกโปรเจคต์ในเครื่องเข้ากับ repository บน github
2. git remote set-url origin https://... --> อัปเดตเปลี่ยนลิ้งค์ Github เดิมให้เป็นลิ้งใหม่
3. git remote remove origin --> ยกเลิกการผูกกับ Github ตัวแัจจุบัน
4. git remote -v --> ตรวจสอบว่าโปรเจกต์ในเครื่องผูกกับ github ไหนบ้าง


# คำสั่งรับ-ส่งข้อมูล Push and Pull
1. git push -u origin nameBranch --> ส่งโค้ดขึ้น github ครั้งแรก และตั้งค่าให้จดจำแบลนช์หลัก
2. git push --> ส่งโค้ดขึ้น Github ในครั้งถัดไป
3. git pull --> ดึงโค้ดเวอร์ชั่นล่าสุดจาก Github ลงมาอัปเดตในเครื่องของเรา
4. git push -u origin <ชื่อ branch> --force --> เป็นการสั่งโค้ดขึ้น git โดยที่ยึดโครงสร้างไฟล์ปัจจุบันตามในเครื่อง
5. git pull --rebae --> ย้ายรากฐาน ของ commit ในเครื่องเราให้ไปต่อท้าย commit ล่าสุดที่อยู่บน Github แบบเส้นตรง
6. git merge --> คือการรวม branch ของเราและของเพื่อนเข้าได้กัน


# คำสั่งจัดการกิ่ง Branches
1. git branch --> ดูว่าในเครื่องมีกิ่งอะไรบ้าง และเราปัจจุบันเราอยู่กิ่งไหน
2. git branch -M main --> เปลี่ยนชื่อกิ่งปัจจุบันที่เราอยู่ให้เป็นชื่อ main
3. git checkout -b <ชื่อกิ่งใหม่> --> สร้างกิ่งใหม่แยกออกมา และสลับไปกิ่งที่เราสร้างทันที
4. git checkout <ชื่อกิ่ง> --> สลับไปทำงานที่กิ่งอื่นที่มีอยู่แล้ว

# คำสั่งยกเลิก commit 
### กรณียังไม่ได้ push
1. git reset --soft HEAD~1 --> ยกเลิก commit แต่ไฟล์ยังอยู่ใน staged พร้อม commit ใหม่
2. git reset HEAD~1 --> ยกเลิก commit และ unstage แต่โค้ดที่แก้ยังอยู่ครบ
3. git reset --hard HEAD~1 --> ยกเลิก commit และลบโค้ดที่แก้ทิ้งทั้งหมด กู้คืนยาก ระวัง!

### กรณี push ไปแล้ว
1. git revert HEAD --> ย้อน commit ล่าสุด
2. git revert 08fc785 -->  ย้อน commit ที่ระบุ (ดู hash ได้จาก git log --oneline)
3. git log --oneline --> ดู log และค่า Hash

# คำสั่งกู้ชีพและแก้ไขปัญหา Troubleshooting
1. git rm --cached <ชื่อไฟล์/โฟลเดอร์> --> ลบไฟล์หรือโฟลเดอร์ออกจากความจำ git แต่ในไฟล์คอมยังปกติไม่ได้หายไปไหน 
2. git rm -r --cached .  --> ล้างแคชไฟล์ทั้งหมดในโปรเจคเพื่อให้ git เริ่มแสกนโครงสร้างไฟล์ใหม่ทั้งหมด
3. git reset --hard HEAD --> ย้อนเวลากลับไปที่จุดบันทึก ล่าสุด มันจะทำการล้างโค้ดที่เขียนค้างไว้และยังไม่ได้ commit ทั้งหมดทิ้งออกไป คำสั่งนี้ทำให้โค้ดที่ยังไม่ได้บันทึกหายถาวร
